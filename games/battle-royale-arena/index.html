Cara Bermain

Jelajahi map besar, kumpulkan senjata, dan kalahkan semua musuh untuk jadi pemenangnya!

Kontrol

W A S D Gerak karakter
Mouse Arahkan & Tembak
Klik Kiri Tembak / Serang
1 - 3 Pilih slot inventory
Tab Ganti slot inventory
Click Klik slot inventory
Shift+1/2/3 Tukar senjata
X / G Buang senjata
RClick Buang dari slot
R Reload senjata / Tank
E Keluar dari Tank
F Ganti mode Tank (Cannon/MG)
ESC Pause game

Sistem Inventory

  • Punya 3 slot inventory seperti FreeFire/PUBG
  • Ambil senjata = otomatis masuk ke slot kosong
  • Ambil senjata yang sudah ada = +ammo
  • Pisau selalu tersedia (slot knuckle)
  • Shift + 1/2/3 = Tukar senjata dengan slot
  • X atau G = Buang senjata saat ini
  • Right Click = Buang senjata dari slot

Senjata

1. Pisau - Serangan jarak dekat
2. Glock 19 - Pistol
3. AK-47 - Assault Rifle
4. M-16 - Assault Rifle
5. AR-15 - Assault Rifle
6. M1 Machine Gun - Mesin
7. Minigun - Mesin berat

Gedung & Tank

  • Tank HANYA ada di dalam gedung!
  • Gedung ada di seluruh map (kotak abu-abu)
  • Masuk gedung = 5% dapat tank!
  • Gedung dengan tank ada tulisan "TANK" di atasnya

Mode Tank (M1 Abrams)

  • Cannon Mode: Damage 50, range 400, fire rate 500ms
  • Machine Gun Mode: Damage 15, range 250, fire rate 50ms
  • Tekan F untuk switch mode
  • Setiap mode punya ammo terpisah

Tips

  • Kumpulkan senjata dari drop (lingkaran warna)
  • Cari Tank (lingkaran hijau besar atau di gedung)
  • Setiap 8 kill = Wave naik + HP recovery
  • Reload saat ammo habis otomatis, atau tekan R manual
